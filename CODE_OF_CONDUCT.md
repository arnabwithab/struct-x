# Code of Conduct

Be direct, stay technical, no personal attacks. We follow the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in spirit: harassment, discrimination, and unwelcome behavior are out of scope
here the same way damage-classification claims are — never shipped.

Report issues via the repo issue tracker. The maintainer (see `LICENSE.md`)
reviews reports and may remove offending content or restrict participation.
